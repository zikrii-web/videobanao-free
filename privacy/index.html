Privacy Policy

Last updated: 23 October 2026

Hum directory hain, tool nahi

VideoBanao Free ek directory website hai. Tum yahan koi video upload ya create nahi karte — card par click karke tum tool ki official website par jate ho. Isliye tumhari photos, videos ya files hamare paas kabhi aati hi nahi।

What we collect

  • No accounts — koi sign-up nahi, isliye hum naam, email ya password collect nahi karte।
  • No media data — tum koi file yahan upload nahi karte।
  • Local preferences only — language aur theme ki choice tumhare apne browser ke local storage me rehti hai।
  • Basic hosting logs — har website ki tarah, hosting provider security aur uptime ke liye standard technical logs (page requested, browser type) rakh sakta hai।

Cookies

Hum tracking ya advertising cookies use nahi karte. Sirf tumhari display preferences (language, theme) local storage me save hoti hain।

Third-party services & external links

Fonts Google Fonts se load hote hain, jo font serve karne ke liye tumhara IP address dekh sakta hai (Google ki privacy policy ke hisaab se). Directory ke links bahari tools ki official websites par jate hain — un sites ki apni privacy policy lagti hai, hum unke liye zimmedar nahi hain. Hum koi tracker, ad script ya analytics script embed nahi karte।

Contact

Privacy par koi sawal ho to contact page se humein likho।
